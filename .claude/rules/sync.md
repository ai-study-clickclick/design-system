# 동기화

- 코드·피그마·사이트 동기화는 자동으로 하지 않는다. 사용자가 스킬을 실행할 때만 한다(토큰·피그마 호출·배포 비용을 줄이기 위해)
- 대화 중 화면을 고칠 때는 프로토타입 코드만 고친다. 피그마에는 반영하지 않고, 끝나면 `/sync`를 안내한다
- 동기화 스킬은 마지막 동기화 이후 바뀐 화면·바뀐 부분만 반영한다. 전체를 다시 생성하지 않는다
- 마지막 동기화 이후 프로토타입과 피그마가 모두 바뀌었으면 멈추고 어느 쪽을 남길지 묻는다
- 피그마에서 디자인 시스템에 없는 컴포넌트·값이 쓰였으면 코드로 옮기지 않고 알린다(시스템 관리자 요청)
- 스킬은 방향별 2개다: `/sync`(코드 → 피그마), `/pull`(피그마 → 코드). 범위는 바뀐 곳과 역할로 정한다. 화면 작업자는 본인 화면만 맞추고, 시스템(`DESIGN.md`·컴포넌트·Variables·메인 컴포넌트) 변경이 보이면 맞추지 않고 알린다. 관리자는 둘 다 맞춘다
- 디자인 시스템 변경은 PR 머지 후 시스템 관리자가 `/sync`로 한 번에 반영한다. 피그마 메인 컴포넌트를 직접 고쳤으면 `/pull`
- 프로토타입 링크는 push할 때 배포된다. 화면마다 push하지 않고 사용자가 "올려줘"라고 할 때 push한다
