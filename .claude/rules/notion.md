# Notion

## Notion 연결

Claude ↔ Notion 연결은 선택이다(팀원 모두가 연결할 수 있는 것은 아니다). 연결돼 있을 때만 아래를 따른다. 목적: AI가 Task 카드를 직접 읽고, 작업하면서 **현재 사용자의 카드**만 상태·내용을 고친다.

연결이 없으면 카드는 사람이 직접 바꾼다. AI는 바꿀 내용(`Status`·PR 링크)을 사용자에게 한 줄로 알려 준다.

- Task DB: `collection://38eb2380-e7d7-80b6-b773-000b16a048a8` (`Step` 값으로 카드를 찾는다)
- 현재 사용자 = Notion 연결 계정의 사용자. 카드 `Assign`에 현재 사용자가 있어야 "내 카드"다

| 대상 | AI가 해도 되는 것 |
|---|---|
| 모든 카드 | 읽기 |
| 내 카드 | `Status` 변경(시작 시 In progress, PR 머지 후 Done), PR 링크·진행 메모를 `Description`이나 본문에 추가 |
| 다른 사람 카드 | 읽기만. 고칠 게 있으면 사용자에게 알리고 담당자에게 전달하라고 안내한다. 사용자가 요청해도 고치지 않는다 |
| 담당자 없는 카드 | 사용자가 "내가 맡을게"라고 요청할 때만 `Assign`에 현재 사용자를 넣는다. 내용(`Description`·본문)은 사용자가 직접 요청할 때만 고친다 |

- 공동 담당 카드(`Assign` 여러 명)의 `Status`는 바꾸기 전에 사용자에게 확인한다
- 카드 삭제, `Assign`·`Due`·`Step`·`Phase`·`Depends`·`Hours`·`AI 설정` 변경, 새 카드 생성은 사용자가 직접 요청할 때만 한다(Backlog 요청 카드 생성 포함)
- 바꾼 뒤에는 무엇을 바꿨는지 사용자에게 한 줄로 알린다
- 연결이 없거나 권한 오류가 나면 Notion을 고치지 않고 사용자에게 알린다

## Notion 작성

Notion 페이지·카드를 쓰거나 고칠 때 따른다.

- 콜아웃 아이콘 기본값은 이모지가 아닌 Notion 아이콘의 기본(진한 회색) 색이다: `/icons/<이름>_gray.svg` (예: `/icons/compass_gray.svg`, `/icons/book_gray.svg`). 사용자가 다른 아이콘을 지시하면 그대로 따른다
- 정의·규칙 본문과 설명용 가이드를 섞지 않는다. 가이드는 토글 제목 안에 넣는다. 블록 전체가 아니라 제목 텍스트에만 노란 배경을 넣고, 앞에 🌟와 띄어쓰기를 붙인다: `### <span color="yellow_bg">🌟 GitHub 가이드</span> {toggle="true"}`. 제목은 기본 "OOO 가이드"이고, 내용에 맞게 바꿔도 된다(예: "🌟 용어사전", "🌟 Task DB 보는 법")
- 가이드 토글 안의 맨 아래에는 본문과 구분하도록 구분선(`---`)을 넣는다
- 반드시 지킬 규칙("꼭 지킬 것")은 강조용 예외로 노란 배경 콜아웃 + ⚠️ 아이콘을 쓴다
- 참고 자료는 페이지 맨 끝 콜아웃 하나에 모은다
- 파일명은 인라인 코드로 쓴다(그냥 쓰면 웹 링크로 자동 변환됨). 굵게 안에 인라인 코드를 넣지 않는다
- 비개발자가 읽는다. 짧은 문장, 쉬운 말, 표 위주로 쓴다
