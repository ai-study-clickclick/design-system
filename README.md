# design-system

딸깍딸깍 AI 스터디 — 클로드로 자연어 디자인 시스템 만들기

- 할 일 · 일정 · 작업 방법 · 규칙 설명: Notion "디자인 시스템 › 프로젝트 실행 계획"
- 지금 상태: [`PROGRESS.md`](PROGRESS.md)
- AI용 규칙: [`AGENTS.md`](AGENTS.md) · [`docs/CONVENTIONS.md`](docs/CONVENTIONS.md) (사람은 Notion 설명을 보면 됩니다)
- Claude Code는 이 저장소를 받은 최상위 폴더(지금 이름은 `design-system`, 이전 전에 받았다면 `AI-Study_clickclick`)를 열어서 작업합니다. 그 위 폴더에서 열면 차단 설정·규칙이 적용되지 않습니다

## 내 PC에서 사이트 보기

처음 한 번 `npm install`로 설치한 뒤, `npm run dev`를 실행하고 브라우저에서 `http://localhost:3000`을 엽니다

- `/docs`: 라이브러리(토큰 · 컴포넌트)
- `/prototypes`: 화면별 프로토타입 목록
