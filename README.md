## 사람이 알아야 할 것

- **작업 위치**: 내 PC의 Claude Code에서 이 저장소를 받은 최상위 폴더(`design-system`)를 엽니다. 그 위 폴더에서 열면 차단 설정 · 규칙이 적용되지 않습니다. 클라우드 세션은 쓰지 않습니다.
- **Git은 Claude에게**: "1-2 작업 시작해줘"로 시작하고, 자리를 뜰 때는 "저장하고 올려줘", 끝나면 "PR 올려줘"라고 합니다. 확실히 아는 게 아니면 직접 하지 않습니다.
- **main에 바로 올리지 않습니다**: 브랜치 → PR → 리뷰 → 머지. main 직접 올리기와 강제 덮어쓰기(force push)는 막혀 있어 "차단됨"이 뜨면 정상입니다.
- **한 작업은 한 사람**: 태스크 1개 = 브랜치 1개 = 올리는 사람 1명. 같은 파일은 한 번에 한 명만 고칩니다(`PROGRESS.md`는 예외).
- **PR**: 리뷰어 2명 이상, 승인 2명이 있어야 Squash merge로 합칩니다. 머지는 PR을 올린 사람이 합니다. 값 · 규칙을 바꿨으면 PR 본문 "근거" 표를 채웁니다.
- **화면 작업**: 프로토타입을 먼저 만들고 `screen/` 브랜치에 올리면 미리보기 링크가 생깁니다. 화면 작업은 올리기까지만 하고 PR은 만들지 않습니다. 피그마는 확정한 뒤 필요할 때만 `/sync`로 만듭니다.
- **없는 UI**: 컴포넌트 19개에 없는 부품이 필요하면 Claude가 "있는 걸로 대신 / 새로 만들기"를 묻습니다. 새로 만들면 임시로 만들고, 확정되면 관리자에게 추가를 요청합니다.
- **작은 결정은 담당자가**: 이름 · 표기처럼 작은 결정은 그 내용을 적는 문서의 담당자가 정하고 팀에 알립니다.
- **공개 저장소**: 파일 · 커밋 · PR에는 성을 빼고 이름만 쓰고, 이메일 · 전화번호 · 토큰 · 키는 올리지 않습니다.
- **Notion**: 내 카드만 고칩니다. 카드에는 할 일 · 결과물 링크만 두고 규칙을 요약하지 않습니다(자세한 건 `.claude/rules/notion.md` "Task 카드").

## 내 PC에서 사이트 보기

Node.js 20 이상(nodejs.org의 LTS 버전)을 먼저 설치합니다. 처음 한 번 `npm install`로 설치한 뒤, `npm run dev`를 실행하고 브라우저에서 `http://localhost:3000`을 엽니다.

- `/docs`: 라이브러리(토큰 · 컴포넌트)
- `/prototypes`: 화면별 프로토타입 목록
